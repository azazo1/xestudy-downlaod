# xestudy-downlaod v0.1.0

Date: 2026-10-19

首个版本, 提供配合 Reqable 抓包使用的小鹅通视频下载服务: 抓包脚本把
`query_video_info` 的响应提交给本服务, 服务解析出 m3u8 地址后并发下载分片,
按需解密, 再拼接成完整视频.

## Highlights

- Reqable 抓到视频信息后自动提交下载任务, 不需要手工复制 m3u8 地址.
- 支持小鹅通视频常用的 AES-128-CBC 加密分片, 未显式给出 IV 时按 HLS 规范用分片序号推导.
- 分片留在磁盘上, 中断或失败后重新触发同一个视频即可续传, 已下载的分片不会重复请求.
- 文件名按 `{原文件名主干}-{标题}.{后缀}` 组合并做净化, 成片直接可读.

## Upgrade Notes

1. 本版本是 Go 实现, 与同名 Rust 版接口一致: 同样监听 `0.0.0.0:8010`, 同样接收
   `POST /upload-video-info`, 保存目录结构也一致 (`meta/`, `segments/`, `videos/`).
2. 替换可执行文件即可, 已有的 `segments/` 目录会被复用, 不必重新下载已完成的视频.
3. 验证方式: 启动服务后访问 `http://127.0.0.1:8010/healthz`, 返回 `{"code":0,"msg":"ok"}` 即正常.

## Features

- 服务: 提供 `/upload-video-info` 提交接口与 `/healthz` 存活检查, 收到 Ctrl+C 时先停止接收
  新任务并等待队列中的任务完成, 再按一次才立即取消下载.
- 下载: 分片并发数由 `--concurrent` 控制, 默认 12; 解密密钥按地址缓存, 同一密钥只请求一次.
- 拼接: 默认按序号直接拼接字节流, 加 `--ffmpeg` 改用 ffmpeg 重新封装.
- 命令行: 提供 `--bind`, `--savepath`, `--concurrent`, `--queue-size`, `--ffmpeg`, `--debug`,
  `--version`; `--savepath` 支持 `~` 开头.
- 抓包脚本: `assets/reqable/query-video-info.py` 只依赖 Python 标准库, 服务地址可用
  Reqable 环境变量 `XESTUDY_SERVER` 覆盖.
- 日志: 关键阶段输出结构化日志, `--debug` 输出 debug 级别并附带代码位置.
